## 📌 Usage Guidelines

### **Where These Assets Are Applied**

| Platform | Assets Used | Purpose |
|----------|-------------|---------|
| 📄 **Resume** | Logo, typography, color palette, header design | Professional document branding |
| 💼 **LinkedIn** | Banner, logo, color scheme | Profile visual identity |
| 💻 **GitHub** | Banner, logo, README styling | Technical portfolio branding |
| 📊 **Portfolio** | All assets | Presentations and project documentation |
| 📧 **Email Signature** | Logo, typography, color palette | Professional communication branding |

### **Design Principles**

- **Consistency**: All materials use the same color palette, typography, and logo placement
- **Simplicity**: Clean layouts with generous white space
- **Professionalism**: Understated elegance over flashy design
- **Scalability**: Vector assets ensure quality across all sizes
- **Accessibility**: High contrast ratios for readability

## 🎯 Brand Applications

### **Resume & Documents**

- **Header**: SJ logo with name and title
- **Typography**: Helvetica Neue for headings, Calibri for body
- **Colors**: Deep navy headers, charcoal text, platinum accents
- **Layout**: Structured sections with clear hierarchy

### **LinkedIn Profile**

- **Banner**: Professional cityscape or abstract design with brand colors
- **Profile Image**: SJ logo or professional headshot with consistent styling

### **GitHub Profile**

- **README**: Structured markdown with consistent heading styles
- **Pinned Repos**: Uniform README styling across all projects
- **Profile Banner**: Technical aesthetic aligned with brand identity

## 📝 Typography Specifications

| Element | Font | Size | Weight | Usage |
|---------|------|------|--------|-------|
| **H1 (Main Titles)** | Helvetica Neue | 32-36pt | Bold | Document titles, main headers |
| **H2 (Section Headers)** | Helvetica Neue | 24-28pt | Semibold | Major sections |
| **H3 (Subsections)** | Helvetica Neue | 18-20pt | Medium | Subsections, categories |
| **Body Text** | Calibri | 11-12pt | Regular | Paragraphs, descriptions |
| **Captions** | Calibri | 9-10pt | Light | Notes, supplementary info |

---

## ✅ Brand Checklist

Before publishing any branded material, ensure:

- ✅ Logo is correctly positioned and sized
- ✅ Color palette matches brand specifications
- ✅ Typography follows hierarchy guidelines
- ✅ Layout maintains professional structure
- ✅ Contrast ratios meet accessibility standards (WCAG AA)
- ✅ Files are high-resolution and properly formatted
